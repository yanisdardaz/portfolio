Write-ups CTF

Méthodologies détaillées de machines que j'ai compromises. Chaque solution est une preuve de raisonnement, pas juste un résultat.

TryHackMe Easy

RootMe

Linux · Web · File Upload

01

Scan & Énumération

Scan nmap -sV : ports 22 (SSH) et 80 (Apache) ouverts. Gobuster découvre un répertoire caché /panel/ avec un formulaire d'upload.

02

Bypass du filtre d'upload

Le serveur refuse les fichiers .php. Contournement via l'extension .php5 — upload d'un reverse shell PHP et exécution via l'URL directe.

03

Privesc via SUID

Recherche de binaires SUID avec find / -perm /4000. Python possède le bit SUID : exploitation via python -c 'import os; os.execl("/bin/bash","bash","-p")' pour devenir root.

Nmap Gobuster PHP Shell SUID
~1h solve user.txt + root.txt
TryHackMe Easy

Simple CTF

Linux · CMS · SQLi

01

Découverte du CMS

Nmap révèle un service FTP (port 21) avec connexion anonyme autorisée. Sur le port 80, Gobuster trouve /simple — un CMS Made Simple 2.2.8 vulnérable à une injection SQL.

02

Extraction du hash via SQLi

Exploitation de la CVE-2019-9053 (time-based blind SQLi) avec un script Python public. Récupération du nom d'utilisateur et du hash MD5 du mot de passe depuis la base.

03

SSH & Sudo Privesc

Crackage du hash avec hashcat + rockyou. Connexion SSH réussie. La commande sudo -l révèle que vim peut être lancé en root : shell root obtenu via :!/bin/bash.

Nmap Hashcat CVE-2019-9053 Vim GTFOBin
~1h30 solve user.txt + root.txt
HackTheBox Easy

Lame

Linux · Samba · CVE-2007-2447

01

Scan & Fingerprint

Nmap détecte un Samba 3.0.20 sur le port 445. Recherche dans Exploit-DB : la version est vulnérable à une exécution de commande via une authentification malformée (CVE-2007-2447).

02

Exploitation directe

Utilisation du module Metasploit exploit/multi/samba/usermap_script. Payload configuré en cmd/unix/reverse. L'exploit injecte un shell dans le champ username via le protocole SMB.

03

Root immédiat

Le shell obtenu s'exécute directement en tant que root — aucune élévation de privilèges nécessaire. Récupération des flags user.txt et root.txt en quelques secondes.

Nmap Metasploit Samba 3.0.20 CVE-2007-2447
~45min solve user.txt + root.txt
